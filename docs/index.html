Core Architecture
Designed as a deterministic, closed-loop pipeline. No unverified code is ever committed to your repository.
01 / DISCOVERY & SEMVER RESOLUTION

Non-Breaking Target Selection

Parses advisory events across package trees. Filters out unmaintained major branches and experimental pre-releases to select the lowest stable patch satisfying the advisory without accidental downgrades.

02 / DETERMINISTIC VERIFICATION GATE

Strict Exit Code 0 Harness

Executes your project's native verification suite (pnpm typecheck, pytest, cargo test, go test) inside the target subproject directory. The gate requires an exact exit code 0 to proceed.

03 / CODE HEALING ENGINE

Multi-Tier Interface Repair

When upgraded dependencies alter imports, function arguments, or configuration schemas, the engine isolates candidate files from error traces and applies surgical repairs before re-verifying.

04 / ATOMIC ROLLBACK GUARANTEE

Zero-Residual Rollbacks

If a package fails verification and cannot achieve clean compilation through code healing, all staged changes are immediately reverted via non-interactive atomic rollback.

Deployment Options
Deploy GreenPR locally on workstations ($0 compute) or integrate into existing CI runners.
OPTION A — LOCAL CLI (ZERO CI COST)

Workstation Execution

Run directly on local development machines before committing code. Consumes 0 GitHub Actions compute minutes.

# Run autonomous remediation:
greenpr

# Verify and stage locally without pushing PR:
greenpr --skip-pr

# Target specific package:
greenpr --package vite --target-version 7.3.7
OPTION B — GITHUB ACTION

Scheduled CI Workflow

Add a 10-line workflow to .github/workflows/greenpr.yml. Runs on your own self-hosted or standard runners.

- uses: actions/checkout@v4
- uses: tech49labs/greenpr@v1
  with:
    api_key: ${{ secrets.GREENPR_API_KEY }}
    github_token: ${{ secrets.GITHUB_TOKEN }}
