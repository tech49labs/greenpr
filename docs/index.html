Architecture

Deterministic, closed-loop execution.

Every remediation follows a deterministic pipeline. If compilation fails and autonomous healing cannot resolve it, the codebase reverts cleanly.

01
Semver Filtering
Parses advisory event trees across branches. Filters out unmaintained legacy major versions and pre-releases to select the lowest stable patch satisfying the CVE without accidental downgrades.
02
Verification Gate
Executes your project's native verification suite (pnpm typecheck, pytest, cargo test, go test) inside the target subproject directory. Requires a strict exit code 0 to proceed.
03
Interface Repair
When upgrades alter imports, function signatures, or configuration options, the engine isolates candidate files from error traces and applies surgical repairs before re-running verification.
04
Atomic Rollback
If a package fails verification and cannot achieve clean compilation through code healing, all staged changes are immediately reverted via non-interactive atomic rollback.

Deployment

Run locally or on CI.

Bring-Your-Own-Compute architecture. Run on local workstations with zero CI cost, or integrate into your existing GitHub Actions runner pipeline.

Option A — Local Workstation CLI ($0 Compute)

Run directly on your local machine before committing code. Consumes 0 GitHub Actions compute minutes.

git clone https://github.com/tech49labs/greenpr.git
cd greenpr
pip install -r requirements.txt

# Run autonomous remediation across your repo:
python remediate.py

# Verify and stage changes locally without publishing PR:
python remediate.py --skip-pr

# Target a specific package directly:
python remediate.py --package vite --target-version 7.3.7
Option B — GitHub Actions Workflow

Drop 10 lines of YAML into .github/workflows/greenpr.yml:

- uses: actions/checkout@v4
  with:
    fetch-depth: 0

- uses: tech49labs/greenpr@v1
  with:
    api_key: ${{ secrets.GREENPR_API_KEY }}
    github_token: ${{ secrets.GITHUB_TOKEN }}
