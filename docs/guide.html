Setup guide

From repository
to reviewed update.

Run GreenPR on infrastructure you control. Start with a scan, inspect one update, and choose what to merge.

Community use is free for public open-source repositories and local personal evaluation. No account or payment details are needed to get started.

1. Install the prerequisites

Use Python 3.11 or later, Git, OSV-Scanner v2, and the package manager used by your repository. Publishing pull requests also requires the authenticated GitHub CLI and a configured Git author name and email on your runner. Use a dedicated runner: package managers and verification commands execute repository code.

2. Install GreenPR separately

Keep the tool outside the project you want to maintain.

git clone https://github.com/tech49labs/greenpr.git
cd greenpr
python -m venv .venv
# Activate .venv using your shell's activation script.
python -m pip install -r requirements.txt

On Windows, you can call the virtual environment directly without activating it:

& C:\tools\greenpr\.venv\Scripts\python.exe C:\tools\greenpr\remediate.py --help

3. Scan your repository

Change into the target repository, then run:

cd /path/to/your/repository
python /path/to/greenpr/remediate.py --scan-only

Scan-only does not install dependencies, run your verification commands, or call a model. Scanning contacts advisory services and, where needed, package registries to verify dependency versions. If the scanner cannot complete, GreenPR reports an error rather than treating missing evidence as a clean result.

4. Verify an update

Start from a clean Git checkout with your changes committed. GreenPR processes one dependency update per run. For an npm project, start with:

python /path/to/greenpr/remediate.py --test-cmd "npm test" --skip-pr

Choose commands that cover all checks required by your project. To require more than one command, repeat the option:

python /path/to/greenpr/remediate.py --test-cmd "npm test" --test-cmd "npm run typecheck" --skip-pr

All selected commands must pass before and after the update. If you omit the override, GreenPR discovers the supported verification scripts in the project. It does not replace a failed test suite with a weaker passing check.

For a separate project in a monorepo, add --project path/to/project and select its verification commands. Each remediation run targets one project ecosystem. Use --scan-only --ecosystem all to inspect multiple ecosystems without changing dependencies.

5. Review the result

Remediation runs in a separate Git worktree. With --skip-pr, GreenPR retains the review worktree and writes a patch and JSON receipt. The original checkout remains unchanged. Inspect the reported paths, manifest and lockfile changes, installed dependency version, and verification results before merging.

The tested npm path includes root projects and npm workspaces. Read the repository documentation for the current adapter acceptance and command options. A successful verification command is evidence of those checks, not a guarantee about every behavior in your application.

Commercial repository licensing

Team costs $49 USD per repository per month. Enterprise costs $899 USD per organization per month. Request Team on GitHub or discuss Enterprise on GitHub. A GitHub account is required. Requests are public: share only non-sensitive information. Never post payment-card details, private repository names or links, source code, credentials, or signed license files. We confirm scope and billing before purchase. This website does not collect payments.

Commercial licenses can be issued for offline verification. When GreenPR provides your signed license file, store it securely and configure GREENPR_LICENSE_FILE with its path. Then use --commercial for commercial runs. Do not edit the signed file or commit it to a public repository.

Optional model-assisted repair

Model repair is disabled by default. Enabling --enable-model-repair can send candidate source files and error traces to your configured provider. Use providers approved for that repository and inspect the proposed changes. Compute and model-provider usage are billed separately.

Get help

Contact GreenPR support through GitHub with your environment and a sanitized error. A GitHub account is required, and requests are public. Remove private paths and repository details from commands and logs. Never post tokens, API keys, payment details, signed license files, or private source code.
