Data and privacy

Know what leaves
your runner.

GreenPR's website provides product information and setup instructions. Dependency maintenance runs on infrastructure you control.

This website

The public website has no account sign-in, payment form, advertising scripts, or analytics trackers. It does not set application cookies. The hosting provider may process normal web-request information to deliver and protect the website. See Cloudflare's privacy policy for its processing of website traffic.

Public licensing and support requests

License and support links open GitHub Issues. A GitHub account is required. Requests, your GitHub username, and any information you submit are public and may be indexed or copied by others. GreenPR uses the information to respond and arrange the next steps for your request. Share only non-sensitive information: never post private repository names or links, source code, API keys, tokens, signed license files, or payment-card details. GitHub processes account and request information under its privacy statement. This website does not collect payments.

Repository maintenance

The runner executes in your environment. Dependency scanning and package installation contact the configured advisory services and package registries. Offline commercial license verification uses the signed license file you configure. Running the local tool does not require a hosted GreenPR account.

Optional model providers

If you explicitly enable model-assisted repair, candidate source files and error traces can be sent to the model provider you configure. Its data handling and retention terms apply. Review your organization's requirements before enabling this option. Having a provider key in your environment does not itself enable model repair.

Questions about your information

Contact GreenPR through GitHub for general questions about this notice. This is a public channel: do not include personal or confidential information in your request. For information stored in your GitHub account or issues, consult GitHub’s privacy statement and account controls.
